# Diet Soda - Product Landing Page

Modern animated landing page with dynamic themes and 3D model viewer.

## Features
- Dynamic theme switching
- 3D model viewer (Google Model Viewer)
- GSAP animations
- Responsive design
- Glassmorphism effects

## Tech Stack
- HTML5, CSS3, JavaScript
- GSAP for animations
- Google Model Viewer
- Google Fonts

## Getting Started
```bash
git clone https://github.com/mugi-sha/soda-website.git
cd soda-website
# Open index.html in browser or use local server
python -m http.server 8000
```
